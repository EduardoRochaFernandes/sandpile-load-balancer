# Security Policy

This is a learning project that runs locally on CSV files you provide; it has no network functionality and handles no
secrets. If you nevertheless find a vulnerability (for example in a dependency or in CSV parsing), please report it
privately through GitHub's **Security > Report a vulnerability** feature on this repository rather than a public issue.
I will respond on a best-effort basis.

The "resilience" and "threat model" documents describe an analogy between the sandpile model and network security; they
are not a security assessment method.
